# RemoteLab
Projeto que simula um ambiente de diferentes redes unificadas em uma infraestrutura gerenciável para fins de estudo documentado.  O objetivo é trabalhar técnicas, ferramentas e conhecimentos de redes, blueteaming, redteaming e arquitetura em nuvem.
